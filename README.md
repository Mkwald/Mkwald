# Projects

## 5" FPV Drone

This is a First-Person View drone designed to be only 5" * 5".  Each part was modelled in CAD to create a more efficient and accurate design process.  Excluding all hardware, this is designed completely from scratch. The frame was tested using FEA in Solid works and has been printed with a honeycomb infill pattern to ensure it will stay intact should this drone crash.  The next step is to run fluid simulations around the toroidal propellers to evaluate their performance.

## Wind Tunnel 

The goal of this project was to build a wind tunnel for studying airflow around insect wings at different static positions. By combining the airflow visualizations from each position throughout the wing's range of motion, it is possible to create a model showing how air moves around an insect during flight. To improve measurement accuracy, the wing models were scaled to twice their original size. This project is still a work in progress. The dimensional calculations have been completed, but I have not yet begun designing the wind tunnel and test setup around those specifications.
